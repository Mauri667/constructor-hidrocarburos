# Constructor de Hidrocarburos

Aplicación web sencilla para construir hidrocarburos (alcanos, alquenos y alquinos) con o sin ramificaciones metil/etil.  
Permite arrastrar recuadros que representan átomos de carbono y muestra el nombre IUPAC básico al costado de la pantalla.

---

## 🚀 Cómo usar

1. Abrí el proyecto en tu navegador:
   - Descargá el repositorio o clonalo con:
     ```bash
     git clone https://github.com/TU_USUARIO/constructor-hidrocarburos.git
     ```
   - Abrí el archivo `index.html` con doble clic.

2. En la interfaz:
   - Usa el botón **Agregar C** para añadir átomos de carbono.
   - Usa los botones para **doble enlace**, **triple enlace** o **ramificación metil/etil**.
   - El nombre IUPAC se actualiza automáticamente en el panel lateral.
